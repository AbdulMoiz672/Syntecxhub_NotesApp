# Syntecxhub NotesApp

A simple notes app built with Next.js. Create, edit, search, and delete notes; notes are saved in your browser's local storage.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## Project structure

- `src/app/page.tsx` - Notes interface and client-side note behavior
- `src/app/page.module.css` - Responsive workspace styling
- `src/app/globals.css` - Global styles and color tokens
